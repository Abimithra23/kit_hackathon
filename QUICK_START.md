## 📍 Navigation Guide

### Public Pages (No Login Required)

1. **Home Page** (`index.html`)
   - Start here to see announcements and featured courses

2. **Browse Courses** (`courses.html`)
   - Use search and filters to find courses
   - Click "View Details" on any course

3. **Contact Us** (`contact.html`)
   - Fill out the contact form
   - View FAQ section

4. **Login/Register** (`login.html`)
   - Try logging in (any email/password works for demo)
   - Choose Student or Teacher role

---

### Student Dashboard (After Login)

Once you login as a **Student**, you can access:

1. **Dashboard** (`dashboard-student.html`)
   - Overview of your courses and performance
   - AI-powered insights and recommendations

2. **My Courses** (`my-courses.html`)
   - View all enrolled courses
   - Continue learning

3. **Assignments** (`my-assignments.html`)
   - View pending, submitted, and graded assignments
   - Submit new assignments

4. **Attendance** (`attendance.html`)
   - View attendance records
   - See calendar view
   - Get AI alerts for low attendance

5. **Grades** (`grades.html`)
   - View current and final grades
   - See GPA and grade analysis

6. **AI Recommendations** (`recommendations.html`)
   - Get personalized study suggestions
   - View weak subject analysis
   - Discover recommended courses

7. **Progress** (`my-progress.html`)
   - Track course completion
   - View achievements and badges
   - See learning statistics

8. **Profile** (`profile.html`)
   - Update personal information
   - Change password
   - Manage preferences

## 🔧 Troubleshooting

### If pages don't look right:

1. **Check file structure:**
   ```
   abi/
   ├── index.html
   ├── courses.html
   ├── login.html
   ├── dashboard-student.html
   ├── (other .html files)
   ├── css/
   │   └── styles.css
   └── js/
       ├── main.js
       ├── auth.js
       └── (other .js files)
   ```

2. **Clear browser cache:**
   - Press `Ctrl + F5` to hard refresh

3. **Try different browser:**
   - Chrome, Firefox, Edge all supported

### If links don't work:

- Make sure all HTML files are in the same directory as `index.html`
- Check that `css` and `js` folders are in the same directory
